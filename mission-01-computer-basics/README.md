# Mission 1: Know Your Computer

## Task 1.1 — Trace an Activity Using IPOS
**Chosen Activity:** Typing a document in a text editor and saving it to disk.

| Stage | What Happens in this Stage? | Hardware / Component Involved |
| :--- | :--- | :--- |
| **Input** | Keypresses are detected as raw signals and converted into character codes by the keyboard controller. | Keyboard |
| **Processing** | The CPU fetches instructions from the text editor program (in RAM), processes each character, updates the document buffer in memory, and sends rendering commands to the display system. | CPU (Processor) and RAM (Memory) |
| **Output** | The operating system's window server draws the updated text on the screen so the user sees the characters appear. | Monitor / Display Screen |
| **Storage** | When the user clicks "Save", the document data is copied from volatile RAM to non-volatile storage, making it persist after power-off. | Solid State Drive (SSD) / Hard Disk |
